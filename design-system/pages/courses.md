# Courses Page

## Goal
Transform the Course Catalog into a searchable tool surface, feeling more like a developer IDE component or data explorer than a simple list of cards.

## Key Elements
1. **Desktop View**:
   - Searchable list/table for fast scanning.
   - Right-side `Course Inspector` drawer to view details without losing list context.
   - Clear filtering and sorting mechanisms.
2. **Mobile View**:
   - Searchable cards (table is too constrained).
   - Filters accessible via chips or a bottom sheet.
3. **Course Inspector Details**:
   - Credits and Category.
   - Prerequisites and Unlocks (what this course leads to).
   - Career relevance and portfolio relevance.
   - Source reliability and related maps.

## Anti-Patterns
- Forcing a data table on mobile screens.
- Overwhelming students with technical metadata in the default view.
- Card dump format that is slow to scan.
