# Visual Maps Page

## Goal
The Visual Maps page is a flagship feature acting as a gallery of visual tools.

## Key Elements
1. **Showcase Gallery**:
   - Each map is presented as a showcase card.
   - Preview visuals for each map type.
2. **Guiding Prompts**:
   - Include questions that the map helps answer (e.g., "ควรลงวิชาไหนก่อน?", "วิชานี้ไปต่ออะไร?").
3. **Clear CTAs**:
   - Easy entry points into the interactive map modes.

## Anti-Patterns
- Static images without interactive elements.
- Presenting maps without context on how to use them.
