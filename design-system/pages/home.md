# Home Page (Mission Control)

## Goal
The Home page serves as the "Mission Control" for freshmen. It should feel like a product-quality dashboard but remain highly readable and approachable, not like a heavy Grafana dashboard.

## Key Elements
1. **Hero Section**:
   - Clear value proposition.
   - Interactive learning graph / node map (subtle, lightweight data-flow lines, pulse nodes).
   - 3 Primary CTAs: 4-Year Plan, Course Search, Tools/Beyond Classroom.
2. **Compact Stat Strip**:
   - 138 Credits
   - 17 Prerequisite Edges
   - 6 Career Tracks
   - 120+ Tools / Sources
3. **Mini Previews**:
   - Mini dependency preview.
   - Mini 4-year path overview.
4. **Quick Start / Search**:
   - Quick start cards to jump into popular sections.
   - Global search entry point.

## Anti-Patterns
- Full-page complex charts that overwhelm new students.
- Vague CTAs.
- Dashboard style without a clear starting point.
