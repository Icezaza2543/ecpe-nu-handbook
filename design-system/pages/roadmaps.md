# Career Roadmaps Page

## Goal
Design the Career Roadmaps page as an interactive "Skill Tree" and "Career Selector", avoiding a plain list of text cards.

## Key Elements
1. **Interactive Selector**:
   - Career cards presented as a class selection screen.
   - Show difficulty, focus area, and suggested starting year.
2. **Selected Career Panel**:
   - Displays a Tier 1-4 Skill Tree.
   - Shows related courses from the curriculum.
   - Lists relevant tools and project ideas.
   - Includes a GitHub portfolio checklist.

## Anti-Patterns
- Long, non-interactive text blocks explaining careers.
- Overly gamer-focused language that reduces the professional tone.
