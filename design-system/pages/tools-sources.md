# Tools & Sources Page (Beyond Classroom)

## Goal
Give the "สิ่งที่มหาลัยไม่ได้สอน" page a "Developer Toolbox / Command Palette / Package Registry" vibe, using progressive disclosure to manage the large amount of content.

## Key Elements
1. **Developer Toolbox Vibe**:
   - Prominent, large search bar.
   - Category Explorer for broad navigation.
2. **Progressive Disclosure**:
   - Show only "Top Picks" by default.
   - Use a drawer/modal/accordion for "All Items".
3. **Item Details**:
   - Include tags, What/Why/When context, and starter actions.
   - Show source reliability and portfolio readiness compactly.
   - Compact Skill Gap Matrix.

## Anti-Patterns
- Displaying all 60+ tools or sources at once.
- Showing full details for all skills in the default view (Scroll Dump).
